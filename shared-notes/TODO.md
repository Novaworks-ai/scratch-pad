# Using a simple TODO.md

We can use a plain Markdown checklist (`- [ ] task`) for personal task tracking — no syntax to learn, renders natively in VS Code and on GitHub. See `templates/TODO.md` for a starter list. Pairs well with the Todo Tree and Pomodoro Timer extensions for task intake and focus time.  There is also a skill in the scatch-pad repo that allows you to extract and add quick action items to your TODO.md

# shared-ideas

> [!WARNING]
> **THIS IS A PUBLIC REPOSITORY.**
> Do NOT use this share ideas private to the organization. if you want to use this general idea, clone the repo locally, and bootstrap a private repo.

Ideas that have been deliberately promoted here — team-visible, tracked in git.

Each promoted idea is **its own file** (kebab-case slug, e.g. `link-discussion-sources.md`)  
rather than an entry in a shared running list. Unlike the single `IDEAS.md` you use for  
personal capture, a file here can be read, edited, and expanded on its own over time as  
the idea develops — without touching every other idea in the process.

An idea doesn't land here just because it was captured; it lands here because someone  
decided, on a second look, that it's worth the team seeing. See the `scratch-ideas`  
Claude skill for the capture → file away → promote flow that feeds this directory.

What a team does with a promoted idea next (turn it into a proposal, a ticket, a spec —  
whatever your own process looks like) is up to that team; this directory is just the  
handoff point, deliberately generic so this repo works the same way for anyone using it.

Keep this directory current. A file for an idea that's been acted on or is no longer  
relevant should be removed.
